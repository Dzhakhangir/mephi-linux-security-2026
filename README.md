## Раздел 2. Мониторинг файлов и процессов
### 2.1. Файлы с битом set-UID
```bash
sudo find / -type f -perm -4000 2>/dev/null
```

### 2.2. Процессы с EUID = 0 и RUID != 0
```bash
ps -eo pid,user,uid,euid,ruid,comm | awk '$4 == 0 && $5 != 0'
```

В ходе выполнения найден процесс `fusermount3`

## Раздел 5. Изучение механизма sudo
Пользователю `user1` разрешено изменять системное время через `timedatectl`.

**Правка `/etc/sudoers` через `visudo`:**
```
user1 ALL=(root) /usr/bin/timedatectl
```

**Проверка от имени user1:**
```bash
sudo timedatectl set-time "2026-01-01 12:00:00"
```
